# COMBO LAB · 街霸 6 研习所

基于 Vue 3 的轻量学习资料站，面向个人大学 Vue 课程期末作业。使用本地 JavaScript 数据和浏览器收藏，不依赖后端服务器或数据库。

## 启动

需要 Node.js 22.12 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。停止开发服务器时按 `Ctrl+C`。

```bash
npm test          # 数据完整性、筛选、本地收藏测试
npm run build    # 生成 dist 文件夹
npm run preview  # 预览构建产物
npm run format   # 统一代码格式
```

网页使用 Hash 路由，例如 `/#/character/ryu?tab=combo`。可以把 `dist` 目录部署到支持静态文件的主机，不需要配置后端路由重写。不要直接双击 `dist/index.html`，请通过开发服务器或静态服务器访问。

## 第一版功能

- JP、A.K.I.（阿鬼）、隆、肯、杰米、不知火舞六名角色。
- 每人 10 个精选招式、12 套连段、8 条套路、2 个教学视频、3 条高手对局资料。
- 拳脚介绍按“拳脚 / 目标连段”和“必杀 / 特殊动作”筛选，不是完整出招表。
- 连段默认显示指令、条件、消耗与选择目标；展开查看用途、帧数及关联套路，不放视频。同组卡片使用原生互斥展开（需要支持 details name 的浏览器）。
- 共 60 条招式、72 套连段，帧数保留各自来源与日期。新增内容和已知差异见 [扩充资料说明](docs/EXPANSION_SOURCES.md)。
- 连段使用统一的可收起筛选面板，可组合筛选角色、难度、起手、资源、位置、绿冲、压制帧数与特殊条件；已选条件可逐项移除，“任意”位置会同时匹配版中和版边。
- 套路按起身设置、帧数陷阱、距离陷阱、立回策略筛选，不显示入门/进阶；关联区分起手被防与击倒之后。
- 高手对局按角色、选手类型、对局类型筛选。
- 角色详情的五个分类可通过 URL 直接访问。
- 指令记谱说明、操作要点展开、复制指令。
- B站真实视频链接，在新标签页打开；不嵌入或托管视频。
- Pinia 管理收藏，localStorage 持久化，支持跨标签同步。
- 响应式 CSS、键盘焦点样式、空状态和未收录页面提示。

第一版没有登录、数据库、视频上传和在线社区。收藏是当前浏览器内的本地状态，清除站点数据会移除收藏。

## 最常修改的地方

### 替换 B站视频

编辑 `src/data/videos.js`。视频记录通过 BV 号生成链接：

```js
video(
  'ryu-video-1', // 稳定唯一 ID
  'ryu', // 角色 ID
  '视频标题',
  'UP 主名称',
  '2026-09-08', // 视频发布日期，不是游戏版本
  '实际的视频BV号',
  '视频内容简介',
  { level: '入门', topic: '基础连段' },
)
```

BV 号应从原视频地址中复制。示例里的文字是字段说明，不要作为真实链接提交。连段、招式或套路通过 `videoId` 指向该角色的相关教学；未经核对具体分 P/时间点时，按钮明确显示“B站相关教学”。

### 修改连段与套路

编辑 `src/data/lessons.js`，保留已有记录 ID 可以继续匹配浏览器内的收藏。

- 连段：标题、指令、难度、资源、成立条件、说明、操作要点、视频 ID、文字来源。
- 套路：`trapCategory` 分类、条件、操作步骤、原理、对手应对与风险、训练建议、视频 ID。
- 帧数陷阱练习时间差抓普通抢招，立回陷阱练习牵制与选择诱导，差合陷阱练习诱出空挥后反击。帧数陷阱目前提供待实测的训练思路，不代表已经验证的具体帧数路线。概念参考：[Frame Trap](https://glossary.infil.net/?t=Frame+Trap) 与 [Spacing Trap](https://glossary.infil.net/?t=Spacing+Trap)。
- 记谱按角色朝右：`>` 是取消，`,` 是目押/追击，`~` 是连打/派生。

### 补充帧数

基础帧数保存在 `src/data/frameReference.json`，对应说明与收尾单招参考在 `src/data/frameStudy.js`。查询日期、来源版本和已知分歧见 [帧数资料口径](docs/FRAME_SOURCES.md)。数值按强度与状态分别展示；D 表示击倒，非攻击动作不具有普通命中 / 被防优势。不要把收尾单招数字当作整条浮空连段的实测结果，也不要把前冲时间减法当作已验证的压起身方案。

### 修改颜色

编辑 `src/assets/styles.css` 中 `:root` 的 CSS 变量。每个角色的强调色在 `characters.js` 的 `color` 字段中。

## 内容核对情况

- 视频链接通过网页检索确认了具体页面和标题；没有假造 BV 号，没有声称已观看全部视频或验证播放。
- 招式与连段保留了文字资料参考，但未在当前游戏补丁逐条实机复测。游戏更新后，应先核对站蹲、距离、中毒、酒等级和烈火槽条件。
- 帧数采用可追溯来源整理，明确区分资料表数值、单招参考与条件推导；本站未实机测量，不提供自编伤害或“当前世界第一”等易过期排名。
- 图片是 Fighters Generation 收录的官方宣传立绘，来源及权利备注见 `docs/ASSET_SOURCES.md`。
- Google 字体不可用时使用系统字体，不影响网站主要功能。

## 测试与演示

运行 `npm test` 检查资料引用、搜索筛选、收藏持久化和异常存储情况。页面同时通过 Vue 编译与生产构建检查。浏览器视觉和实际交互需要按 `docs/DEMO_GUIDE.md` 的清单自行演示；自动化逻辑测试不等于视频可播放或游戏连段有效。

页面渲染测试使用独立的临时缓存，并在结束后清理，不会覆盖正在运行的开发预览缓存。

如果开发预览出现白屏，且浏览器报告 `504 Outdated Optimize Dep`，先停止原开发服务器，再运行 `npm run dev -- --force`，随后刷新页面。这会重建开发依赖缓存，不会删除本地收藏。

可选 WebMCP 功能在浏览器支持时注册读取资料和收藏工具，不影响普通浏览器使用；未在支持该提案的真实浏览器上下文中验证，不属于期末答辩的必要内容。
