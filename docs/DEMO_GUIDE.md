# 期末展示与修改指南

## 建议的五分钟展示

1. 首页：展示六个角色卡片，搜索“阿鬼”或“Ryu”，切换角色类型。
2. 进入隆：介绍 `/character/:id` 动态路由；五个分类共用角色详情页。
3. 实用连段：切换难度、展开操作要点，复制指令。
4. B站：点击相关教学，说明数据中保存的是实际视频地址。
5. 高手对局：按角色和玩家类型筛选，查看观看问题。
6. 收藏：收藏连段和视频，打开收藏页并刷新，展示本地持久化。
7. 代码：打开角色数据、共用卡片组件和 Pinia 收藏 store。

## Vue 知识点对应

| 知识点       | 项目中的例子                                          |
| ------------ | ----------------------------------------------------- |
| `ref`        | 搜索关键词、类型和难度选择                            |
| `computed`   | 筛选结果、收藏内容和当前角色                          |
| `v-model`    | 搜索输入框和下拉选择                                  |
| `v-for`      | 角色、资料和视频卡片列表                              |
| `v-if`       | 空状态、收藏图标、不同资料类型                        |
| Props        | `CharacterCard`、`LessonCard` 和 `VideoCard` 接收数据 |
| Emits        | `EmptyState` 发出重置筛选事件                         |
| Vue Router   | 动态路由、懒加载页面、标签查询参数                    |
| Pinia        | 共享收藏状态和统一收藏操作                            |
| 生命周期     | 注册/清理快捷键、跨标签存储事件                       |
| localStorage | 收藏保存、恢复和异常处理                              |
| CSS          | 网格布局、响应式断点、焦点和减少动画偏好              |

## 演示前手工检查

- 首页六张图片能显示，角色卡能打开对应角色。
- 五个分类切换后 URL 和内容一致，刷新详情页仍可打开。
- 搜索没有结果时有提示，清除筛选后恢复。
- 复制按钮在允许剪贴板的浏览器中有效；拒绝时提示手动复制。
- 收藏和取消收藏立即改变顶部数量和收藏页。
- 刷新页面后收藏还在；两个同源标签页间的收藏会同步。
- 试开每个角色的一条 B站教学和一条对局，核对角色与标题。
- 在窄屏下检查导航、选择框、指令换行和卡片排版。
- 用 Tab 键浏览按钮和链接，检查可见的焦点。

上述为待手工确认清单，不代表已运行浏览器自动化测试。

## 可先简化讲解的部分

`src/utils/webmcp.js` 是可选浏览器增强，不需要拿它做课程重点。答辩集中讲 Vue 组件、路由、数据筛选和 Pinia 即可。

如果老师明确要求服务端增删改查，需要另外增加接口与数据库；当前收藏的增删只发生在本地浏览器，不是在线社区。
