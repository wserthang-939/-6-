# 指令训练判定资料与限制

- 资料基准：Street Fighter 6 Year 4，2026-08-03 调整后版本
- 本页核对日期：2026-09-16
- 网页能力边界：只判断键盘输入序列是否满足本站规则，不模拟命中、硬直、取消窗口和角色状态，因此不能证明招式已实际发动或连段在游戏中成立。

## 来源

1. [《街头霸王6》官方操作手册](https://game.capcom.com/manual/SF6)：经典模式六键布局与基础操作。官方手册没有公开全部底层输入窗口、蓄力残留和容错帧数。
2. [Street Fighter 6 - Input Engine Details](https://rentry.co/35ch3)：社区逆向整理，页面标注最后编辑于 2024-05-17。用于方向路径、输入保持和同时按键的实现参考。
3. [SuperCombo Wiki：Street Fighter 6](https://wiki.supercombo.gg/w/Street_Fighter_6)：角色招式与蓄力要求的交叉参考。

## 当前判定参数

方向输入窗口、45F 后蓄力、10F 后蓄力残留、45F 下蓄力、12F 下蓄力残留和相邻 1F 组合键均来自社区资料或逆向结果，不是 Capcom 公开的统一底层规格，状态统一为“待当前版本训练模式逐帧复测”。参数集中在 `src/trainer/inputConfig.js`，不要写死在界面组件中。

浏览器的 28ms 方向归组、45ms 攻击键归组和 1.5 秒尝试超时只是网页交互参数，不等同于游戏内部判定。

## 游戏内复测清单

- 各角色、各招式分别确认实际蓄力需求；不能把一个招式的数值套给所有角色。
- 逐帧确认后蓄力与下蓄力的残留长度，以及离开方向后是否允许累计续蓄。
- 确认换边帧上的前后转换与蓄力继承。
- 确认 QCF、DP、双 QCF、半圈与冲刺允许的缺省方向、多余方向和保持窗口。
- 确认 OD、斗气迸放等组合键允许的同帧/相邻帧窗口。
