# 学习界面与设置资料

- 连段默认只显示指令、条件与消耗；用途与后续放在展开层，完整帧数及来源再展开。
- 卡片不再显示 B站入口；视频教学、高手对局保留独立栏目。
- 套路按起身设置、帧数陷阱、距离陷阱、立回策略分类。原进退诱空归入立回策略。
- 每位角色新增起身设置练习和距离陷阱验证练习；这些是条件推导，不是实机验证的固定套路。距离练习尚未指定可复现的具体拳脚组合，不能当作现成实战方案。
- 连段与起身设置双向关联。杰米安全跳限定版边、实际 +42F 和跳重拳触及，并要求分别测试反击；不关联不击倒的第一条连段。阿鬼毒发浮空路线不套用地面击倒设置。
- 资料帧数、条件推导、版本敏感标签用于说明可靠性；本站未作游戏内测量，不标注“实机验证”。
- 术语页覆盖项目常用概念，不声称收录街霸六全部术语。帧数仍使用原有版本快照，未宣称当前补丁逐条验证。
